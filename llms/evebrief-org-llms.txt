# openclaw / evm-lab (onchain-risk-oracle at oracle.evebrief.org)

> onchain-risk-oracle is a pay-per-task A2A agent that checks an EVM address (eth, base, bsc, arb, op, polygon) against a curated rug-pull feed and returns a none / low / high / critical risk verdict with labels, reasons, evidence and sources. One skill, one JSON-RPC endpoint at https://oracle.evebrief.org/, gated by x402 v2 payment of 0.01 RLUSD on the XRP Ledger mainnet through the t54 facilitator. The operator name on the card is "openclaw / evm-lab"; the apex domain evebrief.org hosts EveBrief, a waitlist-stage market-briefing product with no API. This file was generated by API Evangelist from the provider's public surface on 2026-09-19; the provider publishes no llms.txt of its own (https://evebrief.org/llms.txt and https://oracle.evebrief.org/llms.txt both 404).

## How to call it

1. Read the card; the only skill is onchain-risk-check. Input: address (required, ^0x[0-9a-fA-F]{40}$), chain (optional enum), deep (bool), fork (bool, with deep).
2. POST a JSON-RPC message to https://oracle.evebrief.org/ carrying the address as a JSON DataPart or plain text.
3. Expect HTTP 402. Read PaymentRequirements from the PAYMENT-REQUIRED header or body; settle 0.01 RLUSD on xrpl:0 to the payTo address through the facilitator within 600 seconds; retry with PAYMENT-SIGNATURE.
4. The result is the outputSchema object: address, risk, labels[], reasons[], evidence, live_tier, feed, sources[], disclaimer.
